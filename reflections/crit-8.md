# Crit 8

**What was the breakthrough that moved the work forward?**

The main breakthrough was treating the game as a set of independent layers rather than building the whole application at once. Separating the Snake rules from the UI, persistence, and later real-time behaviour gave me a stable foundation to build on. This made each new requirement easier to reason about because I could test the game logic, data flow, and player identity separately instead of debugging everything simultaneously.

**What did this work change about who I want to be as a software developer?**

This work made me more interested in being a developer who can design and reason about complete systems, rather than only implementing individual features. I found that decisions about identity, persistence, server authority, testing, and deployment can be just as important as the visible gameplay itself. It also reinforced that I want to work on interactive AI and software systems where product behaviour, backend architecture, and user experience need to work together.
